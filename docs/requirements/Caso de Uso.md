# Casos de Uso

## CdU01 – Emitir Senha

Ator: Cliente

Fluxo Principal:
1. O cliente solicita uma senha.
2. O sistema gera a senha.
3. O sistema apresenta a senha ao cliente.

---

## CdU02 – Chamar Próxima Senha

Ator: Atendente

Fluxo Principal:
1. O atendente solicita a próxima senha.
2. O sistema identifica a senha conforme as regras de prioridade.
3. O sistema exibe a senha no painel.

---

## CdU03 – Rechamar Senha

Ator: Atendente

Fluxo Principal:
1. O atendente solicita o rechamamento da senha atual.
2. O sistema repete a chamada sonora e visual.

---

## CdU04 – Iniciar Atendimento

Ator: Atendente

Fluxo Principal:
1. O cliente comparece ao guichê.
2. O atendente inicia o atendimento.
3. O sistema registra a data e hora de início.

---

## CdU05 – Finalizar Atendimento

Ator: Atendente

Fluxo Principal:
1. O atendente conclui o atendimento.
2. O sistema registra a data e hora de encerramento.
3. O atendente fica disponível para uma nova chamada.
