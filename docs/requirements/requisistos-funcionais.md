## Requisitos Funcionais

RF01 – O sistema deve permitir que o cliente emita uma senha de atendimento.

RF02 – O sistema deve gerar senhas dos tipos SP, SG e SE.

RF03 – O sistema deve gerar numeração automática para as senhas emitidas.

RF04 – O sistema deve permitir que o atendente chame a próxima senha disponível na fila.

RF05 – O sistema deve permitir que o atendente rechame uma senha quando necessário.

RF06 – O sistema deve permitir que o atendente inicie um atendimento.

RF07 – O sistema deve permitir que o atendente finalize um atendimento.

RF08 – O sistema deve exibir em painel as cinco últimas senhas chamadas.

RF09 – O sistema deve permitir que os clientes acompanhem o painel de chamadas.
